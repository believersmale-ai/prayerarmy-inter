# Page Builder (Admin -> Site Content -> Page Builder)

**Reorder** - use the up/down arrows. The hero banner always stays first.
**Visible** off - the section is hidden everywhere, and its menu / footer / quick-link entries disappear too.
**Published** off - the section is a draft: visitors cannot see it, but Preview shows it outlined in gold.
**Add a new section** - text, optional picture or background picture, up to two buttons, and an optional top-menu link. New sections start as drafts.
**Page text** - edit headings, introductions, menu and button labels and the Statement of Faith. In a heading, `|` splits normal text from highlighted text.
**Preview** (top bar) - opens the real website in a new tab with your *unsaved* changes and keeps updating as you type. Nothing is published until you press **Save Changes**. Allow pop-ups for the admin address.

Safety: links must be http(s), mailto, tel or a page on your own site; anything else (for example `javascript:`) is removed by the server. Text is always shown as plain text, never as HTML. Up to 40 custom sections.
Existing sites keep their current order and look until a layout is saved.
